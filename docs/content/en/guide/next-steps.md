## As a reader

Open [Skills](/en/skills) to find executable capabilities and [Workspace](/en/workspace) to understand project and governance relationships. Use global search when the location is unknown.

## As a content maintainer

Decide whether new material belongs in Guide, Skills, or Workspace. Guide pages keep mirrored locale paths and include a clear title, description, tags, and modification date.

## As a developer

Interface code lives under `app/src/`; Guide content lives under `docs/content/`. Run tests, lint, and a production build, then inspect sidebar, body, code blocks, and page navigation on desktop and mobile.
