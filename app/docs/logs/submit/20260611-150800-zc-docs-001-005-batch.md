## ZC-FIX-001: source:check passes (axi-skills / axi-rules drift)

**Root cause**
`source:check` uses `git rev-parse HEAD` to verify the lock pin. In a
shared workspace where multiple agents commit concurrently, the pin drifts
within minutes. The lock must track HEAD, not a frozen snapshot.

- `docs/sources.lock.json` — `axi-skills` commit `2e5c2d6 → ab40fdea`,

  moment of `source:check` exit).
